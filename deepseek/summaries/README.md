# Detailed paper summaries

Drop one file per paper here (HTML or Markdown), then link it from the DATA block
near the top of `../deepseek_papers.html` by setting that paper's `summary` field, e.g.

    summary: "summaries/v41.html"

Paper ids: llm, moe, coder, math, vl, v2, yoco, v3, r1, r1-0528, v31, v32, mhc, engram, v4, v41

The drawer then shows a "Detailed summary" button that opens the file in a new tab.
